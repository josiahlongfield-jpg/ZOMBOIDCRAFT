# Cortana desk mist pad v1 (printed parts)

Original design, no game assets. `python3 model.py out` (needs manifold3d, trimesh) writes `out/pad.glb`, `out/parts.json` and one STL per printed part in `out/stl/`; `python3 build.py` builds the preview page from `template.html`.
Units mm, z up, front at y=0. Sized for a Bambu P2S bed (256 mm). v2: fitted to the Optoma ML1050STi (rear tower layout approved 21 Nov). Not yet approved for printing.
