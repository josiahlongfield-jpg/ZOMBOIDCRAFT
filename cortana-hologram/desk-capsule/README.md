# Cortana desk capsule v1

Pepper's-ghost hologram tower, 620 mm (24.4 in) tall, 300 x 500 mm. Original design, no game assets. `python3 capsule.py out` writes capsule.glb, parts.json and STLs; `python3 build.py` builds the preview page. Not yet approved for printing.
