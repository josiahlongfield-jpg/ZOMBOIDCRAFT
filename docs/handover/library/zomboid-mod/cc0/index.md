Every asset is CC0 1.0 (public domain), from [ambientCG](https://ambientcg.com) (CamelCase folders, license https://docs.ambientcg.com/license/) or [Poly Haven](https://polyhaven.com) (snake_case folders, license https://polyhaven.com/license). Each folder holds the PBR maps plus a LICENSE.txt. ambientCG maps: Color, NormalDX, Roughness, AmbientOcclusion, Displacement, Metalness, Opacity. Poly Haven maps: diff, nor_dx, rough, ao, disp, arm (AO/rough/metal packed), spec, bump.

Atlas/decal sets (LeafSet, Foliage, GraffitiSet, Leaking, AsphaltDamageSet, CardboardSet, RoadLines) carry Opacity maps for cutout or overlay use.
