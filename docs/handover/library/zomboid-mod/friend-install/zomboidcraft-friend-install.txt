ZOMBOIDCRAFT - HOW TO JOIN JOSIAH'S WORLD
Minecraft Java 26.3, Fabric

SETUP
1. Install the Modrinth app: https://modrinth.com/app
2. In the app, make a new profile (instance): Minecraft 26.3, loader Fabric (latest stable).
3. Add the REQUIRED mods below. The Modrinth ones you can search for inside the app,
   it picks the 26.3 Fabric version for you.
4. ZomboidCraft is not on Modrinth: download the jar from the link below, then in the
   profile go to Content > Add content / drop the .jar in (or put it in the profile's mods folder).
5. Launch the profile. Multiplayer > Direct Connection, paste the address Josiah sends you
   (it ends in .e4mc.link), Join.
   You do NOT need e4mc yourself. Only the host needs it.

REQUIRED
- Fabric API ............... https://modrinth.com/mod/fabric-api
- ZomboidCraft (playtest) .. https://github.com/josiahlongfield-jpg/ZOMBOIDCRAFT/releases/download/playtest-build/zomboidcraft-playtest.jar
- Simple Voice Chat ........ https://modrinth.com/plugin/simple-voice-chat
- Voice Bridge for e4mc .... https://modrinth.com/mod/voice-bridge-for-e4mc
  (makes voice chat work through the e4mc link; use version 1.1.0 for 26.3)

OPTIONAL (looks / performance)
- Sodium ................... https://modrinth.com/mod/sodium        (faster rendering, needed for Iris)
- Iris ..................... https://modrinth.com/mod/iris          (shader loader)
- Photon shader ............ https://modrinth.com/shader/photon-shader  (the look Josiah uses; pick it in Video Settings > Shader Packs)
- Particle Rain ............ https://modrinth.com/mod/particle-rain
- Continuity ............... https://modrinth.com/mod/continuity    (connected textures)
- Distant Horizons ......... https://modrinth.com/mod/distanthorizons  (far view distance; heavy on lower-end PCs)

NOT AVAILABLE YET
- Photonics has no Minecraft 26.3 version yet, so skip it for now.

TIPS
- Update the ZomboidCraft jar whenever Josiah says so: same link, always the newest build.
  Delete the old zomboidcraft-playtest.jar first so you only ever have one.
- Your ZomboidCraft version (shown in the Modrinth app's mod list) should match Josiah's.
- Voice: the Simple Voice Chat menu is on Y (ZomboidCraft moves it off V). In game, B talks over a radio.
