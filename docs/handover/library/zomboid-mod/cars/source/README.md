# Car models source (do not commit to GitHub)

american-cars-80s-pack.zip: CGTrader "American Cars 80s Pack"
(https://www.cgtrader.com/3d-model-packs/american-cars-80s-pack), bought by Josiah under the
CGTrader Royalty Free licence (no AI). The licence forbids re-uploading the files, and the
ZomboidCraft repo is public, so the originals live only here.

To rebuild the mod's car files: unzip this, then run
`python3 tools/cars/pack.py <unzipped folder>` from the repo.
