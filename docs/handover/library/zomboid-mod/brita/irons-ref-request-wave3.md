If the real gun has no factory irons (rail only or scope only), please say so in `sources.md` and add one photo that shows its top.

Use free-licence sources only (Wikimedia from his PC, as usual). Save each gun's photos to `/mnt/project-files/zomboid-mod/refs/items/weapons/irons/<folder>/`, with a `sources.md` that holds the links, the licences and one line on whether the gun has factory irons.
