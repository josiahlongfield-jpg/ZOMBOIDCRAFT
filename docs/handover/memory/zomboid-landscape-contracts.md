POWER EVENTS (LOOT 08:28, branch claude/project-thread-jd27hs, reaching playtest on LOOT's next merge): com.zomboidcraft.power.PowerGrid has Event<Changed> OFF and ON, where Changed is (ServerLevel level, String districtId). They fire on the server thread. districtId comes from world.gen.PowerDistricts.id, or PowerGrid.WHOLE ("grid") when the world has no districts. Shutoff: power.shutoffDays (default 14; -1 means off from the start), with each district at its own hour that day. power.alwaysOn is a toggle. LANDSCAPE's substation repair should call PowerGrid.restore(level, id). Other helpers: isOn(level,id), mainsOn/hasPower(level,pos), district(level,pos), offAt(level,id), districts(level). LANDSCAPE still owes: the yard arc and bang on OFF, and the hard repair interaction at a yard that calls restore.
