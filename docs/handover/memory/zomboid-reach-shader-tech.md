- Merged into ENDLESS-NIGHT playtest 4418efbf8 (2026-11-09 13:40), CI green. DORMANT until level glbs carry extras.halo material data: needs PC re-export with lexport2 (TEXLIB, curves, TEXCOORD_1 lightmap uv, COLOR_0 linear vertex light) plus <piece>_lm.png (RGBM, range 2) beside each glb, and per-level atmosphere {exposure, fog rgb, fogDistance, fogMax} in reach.json. Turn off with -Dendlessnight.reach.shader=false.
- Code: client/reach/ReachShader (3 pipelines OPAQUE/BLEND/ADDITIVE, location endlessnight:pipeline/reach_level_*, shaders assets/endlessnight/shaders/core/reach_level.vsh/.fsh, ENTITY vertex format, ReachMaterial std140 UBO 512 B per material); ReachGlb.HaloMaterial/Picture; ReachMeshes.drawHalo after the plain path.
- Packing: UV1.x = light mode (0 lightmap, 1 vertex, 2 none); UV2 = lightmap uv*32767; Color = sqrt(E/4) vertex light. Frame values ride in TextureMat (col0 exposure,fogDist,fogMax,lmRange; col1 fog rgb; col2 sun dir view space).
- 26.3 API facts (probed): DynamicGpuData.writeTransform(mv, textureMat) and 4-arg (mv, colour, offset, textureMat); RenderSystem.getSamplerCache().getClampToEdge/getRepeat(FilterMode, mips); CommandEncoder.writeToTexture(tex, NativeImage, mip, ...); custom pipelines compile on demand via RenderSystem.getCompiledPipeline, no registry.
- Per-mission atmosphere (cfxs exposure stops/target, fogg colours) extracted in cloud real/atmo.json; preview calibration key = 3.8*target (m20 -> exposure ~2), clamps 2^(stops+1), fog colour = raw[14:17], fogd = 3.048*max(raw[5],raw[13]) clamped 1500-8000.
- EXPORTER BUG FIXED 2026-11-09 14:50 (cloud lexport2.py): cluster (terrain) lightmap-uv buffers only cover the lightmapped parts (first N vertices; water/decal parts with vertex type 138 come after), so the old `len(LUV)>=cnt` test dropped TEXCOORD_1 from ALL terrain: every mission's ground was lit by a fake sun. Now per part `vu.max()<len(LUV)`. ALL glbs on the PC predate this: the PC re-export must use the fixed lexport2 (backup tools to project files before the PC session).
- Material gotchas (2026-11-09): shader group strings can carry a trailing space ('rmw ' water) so trim before comparing; water has no textures (needs its own look: deep colour water_color_pure + fresnel to fog/sky); additive sky layers must fade with fog (c*=1-f), not mix to fog colour, or skies blow out white; terrain global_albedo_tint scales layers; New Alexandria needs height haze under the towers (preview hfb=350 hft=120 hfd=6, metres).
