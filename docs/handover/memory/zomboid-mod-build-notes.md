Build workflow: this cloud env can't reach Fabric/Mojang hosts, so build via GitHub Actions. Read logs with GitHub MCP get_job_logs (gh log download is blocked). On failure CI runs .github/probe.sh (javap of real 26.3 classes) and then prints compile errors; edit probe.sh to look up names. Download release assets with gh api .../releases/assets/ID and Accept: application/octet-stream.
26.3 name gotchas: EntityTypes.ZOMBIE (not EntityType), monster.zombie.Zombie, GuiGraphicsExtractor.text(), HudElement.extractRenderState, Commands.hasPermission(Commands.LEVEL_GAMEMASTERS), sendOverlayMessage, Fabric creativetab.v1.CreativeModeTabEvents, ServerEntityEvents in event.lifecycle.v1. Versions: loader 0.20.1, loom 1.19.3 (needs Gradle 9.8+), fabric-api 0.165.0+26.3, Java 25.
Delivery: the Claude app can't download .jar files from project files; give Josiah the GitHub release link (github.com/josiahlongfield-jpg/ZOMBOIDCRAFT/releases/download/latest/<jar>, repo is public) or a .zip copy.
26.3 sunburn lives in private Mob.burnUndead() (Zombie.isSunSensitive alone doesn't stop it); MobMixin cancels it for walkers (v0.1.1). Manual probe workflow: gh workflow run probe.yml, runs .github/probe.sh.
CI smoke test boots a dedicated server and summons zombies via a stdin FIFO. Preview tools: tools/gen_zombie_skins.py (skins + sheet), tools/mockup/ (three.js Photon-style mock via Playwright).
Related: [[minecraft-zomboid-mod]].

- Zombie art tools (2026-10-24): tools/gen_zombie_skins.py (64px base), tools/gen_hd_skins.py (4x 256px + LabPBR _s/_n, DirectX normals), tools/gen_blockbench.py, tools/mockup/{sheet,photon}.html previews (three.js in scratchpad mock/ via npm, served on :8765). Josiah approved 4x. v0.3.3 ships walker_hd/ (15 outfits x 3 skins x 4 damage levels incl. bones-showing, 180 skins) + arm stumps (skipDraw on arm, stub+bone child parts; bone UVs at 56,16/56,24). Settings look.hdSkins, look.maxGore 0-3, look.missingLimbChance. Missing legs wait for crawlers. v0.3.4 = realism pass (grade(), stain() soaked blood). Josiah's in-game test: Photon looked like it did nothing for mobs; Iris DOES load _n/_s for SimpleTexture entities, so likely Photon's LabPBR option was off. Offered: texture-from-concept (he renders front/back per outfit ~1000px, Claude projects onto skin faces).
- Concept-art pipeline (2026-10-24): Josiah is getting an art AI to paint one 2048x1216 turnaround sheet per outfit from project-files zomboid-mod/art-brief/ (ZOMBIE-TEXTURE-BRIEF.md + zombie-template.png, magenta bg, FRONT/BACK/LEFT/RIGHT views, files named <outfit>.png). Run `python3 tools/import_concept_skins.py IN_DIR walker_hd_dir --preview DIR` (commit e82f3f1, tested round-trip on synthetic sheets: visible faces match within ~2/255). It makes 3 tones x 4 levels with _s/_n. Then preview with tools/mockup sheet/photon, get approval, regenerate Blockbench, bump version, push.
- 26.3 screens open via Gui.setScreen(Screen) (minecraft.gui), NOT Minecraft.setScreenAndShow; hook Gui for screen swaps. Window: getWidth/getHeight (framebuffer), getGuiScale/setGuiScale(int), calculateScale(int, boolean); Options.guiScale()/forceUnicodeFont(); Minecraft.resizeGui(). Field kit build 2 (commit 7dd0f3c) uses this.
- 26.3 sound/GUI names (2026-10-25): SoundInstance.resolve is now getOrResolve(SoundManager); Sound.getLocation(); WeighedSoundEvents.getSound(RandomSource). HUD textures: graphics.blit(RenderPipelines.GUI_TEXTURED, id, x, y, u, v, w, h, texW, texH); Fabric VanillaHudElements.MISC_OVERLAYS exists. Item.getName needs a stack (use getDefaultInstance().getHoverName()).
- Crash reports (2026-10-26): Josiah's Modrinth profile is C:\Users\josia\AppData\Roaming\ModrinthApp\profiles\MEDIEVAL GLOOM (1) (has crash-reports\, logs\, mods\). He granted folder access once; read crash files with device_stage_files instead of asking him to upload. Lesson: never call a random-rolling picker (e.g. GhostPower.lit) twice for the same block; a null BlockState into ClientLevel.setBlock crashes the game.
- Changed config defaults (2026-10-27): ZcConfig.defaultsVersion + upgrade() moves old defaults in saved files to new ones (bump DEFAULTS, add a step). Use it instead of renaming fields. ModSounds lives in com.zomboidcraft.combat.
